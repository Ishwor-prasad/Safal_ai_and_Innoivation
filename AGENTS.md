# AGENTS.md

## What this is

React + Vite SPA with an Express backend. Corporate website + AI products for SAFAL AI (Nepal). Gemini API powers chatbot and lesson planner; Supabase stores form submissions. Bilingual (English/Nepali). Deployed to GitHub Pages at `safalai.com.np`.

## Commands (run from `src/`)

```bash
npm run dev        # Vite dev server + Express API on port 3000
npm run build      # Vite build → dist/ + esbuild → server.cjs (production bundle)
npm run lint       # tsc --noEmit (type-check only, no ESLint)
npm run clean      # rm -rf dist server.js
```

**There are no tests, no formatter, and no ESLint.** `lint` is just the TypeScript compiler in check mode.

## Repo structure

- Root `index.html`, `server.cjs`, `server.cjs.map`, `CNAME` → **built/deployed artifacts** (do not edit directly)
- `src/` → all source code; has its own `package.json`, `tsconfig.json`, `vite.config.ts`
- `supabase/migrations/` → SQL schema (consultation_bookings, contact_inquiries, course_enrollments, newsletter_subscribers, teacher_ai_logs)

### Source layout (`src/`)

| Directory | Purpose |
|-----------|---------|
| `pages/` | `HomePage.tsx` (main), `VibeCodingPage.tsx` (course page) |
| `components/sections/` | All homepage sections (Hero, Sandbox, Solutions, Training, Contact, etc.) |
| `components/layout/` | Navbar, Footer, WhatsAppDock |
| `components/modals/` | ConsultationModal, SyllabusModal |
| `components/chatbot/` | ChatbotDrawer |
| `hooks/` | Custom hooks: useNavigation, useSandboxCompiler, useChatbot, useConsultationModal, useContactForm, useEnrollmentForm |
| `services/` | Supabase form submission logic (consultation, contact, enrollment, newsletter, storage, webhook) |
| `context/` | AuthContext (Supabase auth) |
| `lib/` | `supabase.ts` — singleton client, exports `isSupabaseConfigured` |
| `types/` | TypeScript interfaces |
| `data.ts` | All static content (services, products, testimonials, case studies, team, course data) |
| `translations.ts` | Nepali translations (mirrors data.ts exports) |

### Routing

SPA with client-side routing (no react-router — manual path state via `useNavigation` hook):
- `/` → HomePage
- `/courses/vibe-coding` → VibeCodingPage
- Anything else → 404 page

## Key gotchas

1. **`server.cjs` at root is a built artifact** — generated by `esbuild server.ts --bundle`. Edit `src/server.ts` instead.
2. **Root `index.html` is the built deploy file** — edits belong in `src/index.html`.
3. **`DISABLE_HMR` env var** — when set to `"true"`, Vite disables file watching/HMR (used in AI Studio to prevent flickering during agent edits).
4. **Tailwind CSS v4** — uses `@theme` directive in `index.css`, not a `tailwind.config.js`. Custom colors are defined as CSS variables (e.g., `--color-brand: #16A34A`).
5. **`@` path alias** — maps to `src/` root (configured in both `vite.config.ts` and `tsconfig.json`).
6. **Gemini API** — model is `gemini-3.5-flash` via `@google/genai` client. `GEMINI_API_KEY` is server-only (`process.env`). Without it, API routes return simulated/mock responses.
7. **Supabase** — `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are client-side env vars. Without them, forms fall back to simulated mode (check `isSupabaseConfigured`).
8. **No i18n library** — translations are manual. English content lives in `data.ts`, Nepali in `translations.ts`. Any new user-facing string needs both.

## Environment variables

See `.env.example` for the full list:
- `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` — Supabase (client-side)
- `GEMINI_API_KEY` — Gemini AI (server-side only)
- `VITE_N8N_WEBHOOK_URL` — optional n8n automation webhook
- `APP_URL` — defaults to `http://localhost:3000`

## Design system

- **Fonts:** Inter (body), Space Grotesk (headings/display), JetBrains Mono (code)
- **Brand color:** emerald green (`#16A34A`) with light/dark variants
- **Dark sections:** custom `.dark-section` class with emerald-tinted dark gradients
- **Animations:** custom utilities in `index.css` (float-bob, fade-in-up, shimmer, ring-pulse, etc.)
- **Motion library:** `motion` (v12) for React animations

## Adding new types/data

1. Add interface to `src/types/index.ts`
2. Add data to `src/data.ts`
3. Add Nepali translations to `src/translations.ts`
4. Components consume via props from `data.ts` exports
